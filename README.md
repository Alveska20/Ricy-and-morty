Rick and Morty - Personagens

Site feito para o trabalho de Desenvolvimento Front-end. A página consome a
[Rick and Morty API](https://rickandmortyapi.com/) e mostra os personagens em cards.

Tecnologias
- HTML
- CSS
- JavaScript

Como funciona
- O JavaScript usa o `fetch` para buscar os personagens na API
- Os cards são criados dinamicamente com `createElement` e `appendChild`
- Cada card mostra nome, imagem, status, espécie e local
- O coração no card serve para favoritar o personagem

Como rodar
Basta abrir o arquivo `index.html` no navegador.
